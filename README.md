# 🎬 CRUD Filmes Java

Este é um projeto de um sistema simples de **Cadastro de Usuários** utilizando Java com **Swing** para a interface gráfica e **Maven** como gerenciador de dependências.

O objetivo é oferecer uma interface amigável para **cadastrar**, **visualizar**, **editar** e **excluir** registros de usuários em um sistema local.

---

## 💻 Tecnologias Utilizadas

- **Java 8+**
- **Swing (Java GUI)**
- **Maven**
- **MySQL** (ou outro banco relacional, se aplicável)

---
